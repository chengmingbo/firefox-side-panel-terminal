Side Panel Terminal

Settings and helper installation.

Native helper

The extension talks to a small Go binary on your machine over Firefox's native messaging API. The install script writes the JSON manifest Firefox expects. 


        

          
          
          
          
        

        

          Manual installation
          
    
            
  1. 
              Build the helper:
              ./scripts/build-helper.sh
            
    2. 
            
  2. 
              Copy
              native/firefox_side_panel_terminal_host.json
              into Firefox's NativeMessagingHosts directory:
              
      
                
    • macOS: ~/Library/Application Support/Mozilla/NativeMessagingHosts/
      • 
                
    • Linux: ~/.mozilla/native-messaging-hosts/
      • 
                
    • Windows: registry key under HKCU\Software\Mozilla\NativeMessagingHosts\firefox_side_panel_terminal_host
      • 
              
    
            
    3. 
            
  3. 
              Replace /ABSOLUTE/PATH/TO/firefox-side-panel-terminal-host
              in the manifest with the absolute path to the helper binary.
            
    4. 
            
  4. Restart Firefox.
    5.
